# 🔬 Component configurations

[ablation_configs.py](ablation_configs.py) defines the supervised source control, MS-IDG, identity-only PMR, relational-only PMR, combined PMR, and full AIDA switches.

Select an overlay with `--ablation NAME`. The overlay is applied before explicit overrides. All experiment settings are saved in `config.json`.

See [the component table and controlled-run instructions](../../docs/EXPERIMENTS.md#component-switches).
